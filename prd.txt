# CineTrack Mobile - Complete Project Summary

## Project Overview
**CineTrack Mobile** is a VFX (Visual Effects) task management and collaboration mobile application built with React Native and Expo. It provides a beautiful, minimal, iPhone-style UI for VFX artists and managers to manage tasks, communicate via chat, track project progress, and collaborate on shots.

**Version**: 2.1  
**Project ID**: t9kmsnmkfkaapqhxunjap  
**Expo SDK**: 54.0.0  
**Bundle Identifier (iOS)**: app.rork.cinetrack-chat-mobile  
**Package Name (Android)**: app.rork.cinetrack_chat_mobile

## Core Features

### 1. User Roles
The app supports two distinct user roles with different permissions:

#### Artist Role
- View assigned tasks
- Update task status (assigned → in-progress → review)
- Upload work-in-progress (WIP)
- Task-level chat
- Direct messaging with managers
- View limited project/shot information
- Receive push notifications

#### Manager Role
- All Artist permissions, plus:
- View all tasks across all projects
- Assign tasks to artists
- Create new tasks
- Approve/review work
- Shot-level chat
- Broadcast messages to team
- Full project and shot visibility
- Team management

### 2. Navigation Structure

#### Bottom Tab Bar (4 Tabs)
```
Dashboard | Projects | Chat | Profile
```

- **Dashboard**: Task list with segmented control (Assigned/Completed)
- **Projects**: List of active projects with progress tracking
- **Chat**: Organized chat list (Pinned, Unread, DMs, Task Chats)
- **Profile**: User info, role switcher, app info

### 3. Task Management

#### Task Statuses
1. **Assigned** (yellow/warning)
2. **In Progress** (cyan)
3. **Review** (purple)
4. **Completed** (green)

#### Task Priority Levels
- **Low**: Gray indicator
- **Medium**: Yellow/warning indicator
- **High**: Red/error indicator

#### Task Features
- Shot code tagging
- Due date tracking
- Description and metadata
- Unread message count
- Status update workflow
- Integrated task chat

### 4. Chat System

#### Chat Types
1. **Direct Messages (DM)**
   - One-on-one conversations
   - Artist ↔ Manager
   - Artist ↔ Artist

2. **Task-Level Chat**
   - Linked to specific tasks
   - Automatic context tagging
   - WIP discussion
   - Preview in task detail

3. **Shot-Level Chat** (Manager only)
   - Team collaboration per shot
   - Multiple participants
   - Project-scoped

#### Chat Features
- iMessage-style bubble UI
- Avatar display
- Timestamp formatting
- Unread count badges
- Message sections (Pinned, Unread, DMs, Task Chats)
- Typing in text input
- Send button with icon
- Keyboard avoidance
- Auto-scroll to latest

### 5. Projects & Shots

#### Project Features
- Thumbnail images
- Progress tracking (completed/total shots)
- Deadline display
- Progress bar with percentage
- List view with cards

#### Shot Features
- Unique shot codes (e.g., "NR_010")
- Associated project linking
- Task count tracking
- Thumbnail preview
- Deadline information

## State Management

### AppContext (Global State)
The app uses `@nkzw/create-context-hook` to create a type-safe context provider. Located in `context/AppContext.tsx`.

#### Stored State
- `currentUser`: Active user object
- `users`: All users in the system
- `tasks`: All tasks
- `chats`: All chat threads
- `projects`: All projects
- `shots`: All shots
- `messages`: Record of chat messages by chat ID
- `isLoading`: Initial load state

#### Computed Values
- `myTasks`: Tasks assigned to current user
- `assignedTasks`: Tasks with "assigned" status
- `inProgressTasks`: Tasks with "in-progress" status
- `reviewTasks`: Tasks with "review" status
- `completedTasks`: Tasks with "completed" status
- `allTasks`: All tasks (for managers) or myTasks (for artists)
- `myChats`: Chats involving current user
- `unreadChatsCount`: Number of chats with unread messages

#### Actions
- `switchUser(userId)`: Change current user
- `switchRole()`: Toggle between artist/manager (for demo)
- `updateTaskStatus(taskId, status)`: Update task status
- `getTaskById(taskId)`: Get task by ID
- `getProjectById(projectId)`: Get project by ID
- `getShotById(shotId)`: Get shot by ID
- `getShotsByProjectId(projectId)`: Get shots for project
- `getTasksByShotId(shotId)`: Get tasks for shot
- `getChatById(chatId)`: Get chat by ID
- `getMessagesByChatId(chatId)`: Get messages for chat
- `getUserById(userId)`: Get user by ID

#### Persistence
- User ID is persisted to AsyncStorage under key `"cinetrack-current-user"`
- Loaded on app initialization
- Updated when switching users/roles

## Routing & Navigation

### File-Based Routing (Expo Router)
The app uses Expo Router's file-based routing system, similar to Next.js.

#### Route Mapping
| File Path | Route | Description |
|-----------|-------|-------------|
| `app/(tabs)/index.tsx` | `/` | Dashboard (default) |
| `app/(tabs)/projects.tsx` | `/projects` | Projects list |
| `app/(tabs)/chat.tsx` | `/chat` | Chat list |
| `app/(tabs)/profile.tsx` | `/profile` | User profile |
| `app/task/[id].tsx` | `/task/:id` | Task detail |
| `app/chat/[id].tsx` | `/chat/:id` | Chat conversation |
| `app/project/[id].tsx` | `/project/:id` | Project detail (stub) |
| `app/shot/[id].tsx` | `/shot/:id` | Shot detail (stub) |

#### Navigation Modes
- **Tabs**: Bottom tab bar (always visible on main screens)
- **Stack**: Card-style push navigation (task/chat/project/shot details)
- **Modal**: Could be added for future features

#### Header Configuration
- Global header style: Dark background (#2A2D35), white text
- Tab screens: Headers hidden (custom headers in component)
- Detail screens: Standard header with back button
- Customizable per-screen via `options` prop

## Screen Details

### 1. Dashboard (`app/(tabs)/index.tsx`)
**Purpose**: Main task view for current user

**Sections**:
- Header with greeting and role subtitle
- Segmented control (Assigned / Completed)
- Task list (cards)
- Empty state with robot + CTA button

**Interactions**:
- Tap task → Navigate to task detail
- Tap "Contact Your Manager" → Navigate to DM chat
- Switch segments → Filter tasks

**Empty State**:
- Robot illustration with glow
- "No tasks assigned yet!" message
- "Contact Your Manager" button

### 2. Projects (`app/(tabs)/projects.tsx`)
**Purpose**: View all active projects

**Features**:
- Project count in subtitle
- Thumbnail images (160px height)
- Progress bar with percentage
- Completed vs total shots
- Deadline display
- Tap to view project details

### 3. Chat List (`app/(tabs)/chat.tsx`)
**Purpose**: Organized view of all conversations

**Sections** (conditional rendering):
1. **Pinned**: `isPinned === true`
2. **Unread**: `unreadCount > 0 && !isPinned`
3. **Direct Messages**: `type === "dm" && unreadCount === 0 && !isPinned`
4. **Task Chats**: `type === "task" && unreadCount === 0 && !isPinned`

**Chat Item Features**:
- Avatar (or default Dicebear avatar)
- Name
- Last message snippet
- Timestamp (HH:MM format)
- Unread badge

### 4. Profile (`app/(tabs)/profile.tsx`)
**Purpose**: User settings and role management

**Content**:
- Large avatar (100x100)
- User name
- Role badge (Artist/Manager)
- Email address
- **Role Section**: Switch between roles (demo feature)
- **About Section**: App description
- **Sign Out Button**: Outlined in red (non-functional)

### 5. Task Detail (`app/task/[id].tsx`)
**Purpose**: Full task information and actions

**Content**:
- Shot code and status badge
- Task title and description
- Metadata table:
  - Priority
  - Assigned to
  - Assigned by
  - Due date
- **Chat Preview Card**: Link to task chat with unread count
- **Actions Section**: Status update buttons

**Status Workflow**:
- `assigned` → "Start Working" → `in-progress`
- `in-progress` → "Submit for Review" → `review`
- `review` → "Mark Complete" → `completed`

### 6. Chat Conversation (`app/chat/[id].tsx`)
**Purpose**: Real-time messaging interface

**Features**:
- Message bubbles (left/right aligned)
- Avatar for other users
- Sender name (for non-current user)
- Message content
- Timestamp (HH:MM)
- Different bubble colors (gray vs purple)
- **Input Field**: Rounded, multi-line (max 100px height)
- **Send Button**: Glowing accent circle with icon
- **Keyboard Handling**: KeyboardAvoidingView for iOS

**Message Layout**:
- **Other user**: Left-aligned, gray bubble, avatar on left
- **Current user**: Right-aligned, purple bubble, no avatar

### 7. Project Detail (`app/project/[id].tsx`)
**Status**: Stub implementation

**Current**: Shows "Project details coming soon..."

**Future**: Will show shots, tasks, team members, progress

### 8. Shot Detail (`app/shot/[id].tsx`)
**Status**: Stub implementation

**Current**: Shows "Shot details coming soon..."

**Future**: Will show shot info, tasks, team chat

## Key Design Decisions

1. **No Backend Initially**: Using mock data to prototype UX quickly
2. **File-Based Routing**: Expo Router for scalable navigation
3. **Minimal Dependencies**: Only essential packages to reduce bundle size
4. **Dark-First Design**: No light mode (VFX studios prefer dark UIs)
5. **Role Switcher**: Built-in demo feature for testing both user types
6. **Platform Agnostic**: Web + mobile support from day one
7. **TypeScript Strict**: Type safety to prevent runtime errors

---

## Known Issues & Limitations

1. **No Real Backend**: All data is local and resets on reload
2. **No Push Notifications**: System not implemented
3. **No Image Upload**: WIP sharing not functional
4. **Stub Detail Screens**: Project and Shot screens incomplete
5. **No Search**: Large datasets will be hard to navigate
6. **No Error Handling**: Assumes all operations succeed
7. **No Loading States**: Beyond initial app load
8. **Hard-Coded Chat Links**: Task detail always opens "chat-2"
9. **No Message Sending**: Chat input doesn't save messages
10. **No Real-Time Updates**: Changes don't sync across instances
